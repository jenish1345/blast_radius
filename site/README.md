# Blast Radius — UI

Marketing / demo site for [Blast Radius](https://github.com/jenish1345/blast_radius), a preflight gate
for autonomous agents. React 19 + Vite + Tailwind CSS v4, no animation libraries. Art direction: risograph print on bone paper —
Bricolage Grotesque + Instrument Serif, hard ink outlines, three spot colours. The page is interactive:
every click sends a shockwave through the dot field and the hero letters, and the playground lets you
run the failure and the fix yourself.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

Lives in `site/` (the operator console stays in `ui/`). See
[`SUBMISSION.md`](../SUBMISSION.md) for the hackathon checklist.
